Current number of decoded frames buffered in the device's bounded playback queue. Zero for devices that do not maintain such a queue.

Cumulative number of playback frames dropped by the queue's backpressure policy for the current connection — a non-zero value indicates the RX path is outpacing playback. Zero for devices that do not maintain a bounded playback queue.
