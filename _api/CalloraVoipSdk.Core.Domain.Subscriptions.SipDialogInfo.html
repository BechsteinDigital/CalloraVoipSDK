Remarks

This is the busy lamp. Subscribe to the dialog package of an extension and each notification says whether it is idle, ringing, or on a call — the difference between a telephone system that shows its colleagues and one that does not.

Partial updates are the trap. A document is full or partial: a full one lists every dialog and therefore says "everything not mentioned is over", a partial one carries only what changed and says nothing about the rest. Treating a partial document as complete clears a lamp that should still be lit — so IsFullState is exposed rather than smoothed away, and a consumer that ignores it will get it wrong in exactly that one direction.

Version comes with the same warning: notifications may arrive out of order, and a document older than the one already applied has to be dropped rather than merged.
