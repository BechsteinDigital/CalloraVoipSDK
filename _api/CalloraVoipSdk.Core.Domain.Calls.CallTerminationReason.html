Protocol-neutral description of why a call terminated, surfaced on the public call surface. It is populated for both locally and remotely initiated terminations and is readable at (and before) the Terminated state change. SipStatusCode and ReasonPhrase carry the raw SIP detail when the termination came from SIP signaling; Category and TerminatedBy classify it without requiring SIP knowledge.

Parameters

code int?

The terminating SIP status code, or null when the termination carried no SIP response status (a BYE-based teardown or a non-SIP fault).

wasConnected bool

Whether the call had reached the connected/established state before it ended. Only consulted for the code-is-null case: a null-status teardown is a normal completion only if the media session was actually up (a graceful remote BYE). A null-status teardown that never connected (dial/ring abort with no SIP failure response — a transport drop or an internal fault) is a technical Failed, matching the reference-stack consensus (Twilio failed, Ozeki Error), not a false Completed. A non-null code is classified purely from the status and ignores this flag.

CallTerminationCategory

The protocol-neutral category for the status.
