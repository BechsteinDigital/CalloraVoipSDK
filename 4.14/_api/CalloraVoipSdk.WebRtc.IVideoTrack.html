Namespace

A handle to an outbound video track added before the first offer with AddVideoTrack() (its own m=video line on the shared BUNDLE transport). Send encoded frames on this track with SendFrameAsync(ReadOnlyMemory<byte>, uint, CancellationToken); each track carries its own SSRC, so frames sent on distinct handles never collide (RFC 3550 §8.1).

public interface IVideoTrack

Remarks

The multi-track surface is preview-grade: tracks must be added before CreateOffer() (mid-call add / renegotiation is a later package). Adding a track supplements the implicit primary video track that EnableVideo enables; the frameless SendVideoFrameAsync(ReadOnlyMemory<byte>, uint, CancellationToken) keeps addressing that primary track.

SendFrameAsync(ReadOnlyMemory<byte>, uint, CancellationToken)

Packetises and sends one already-encoded video frame on this track. The app owns the codec (transport-only). Suppressed until the DTLS handshake keys the transport; a no-op when the negotiated directions do not carry outbound video on this track.

SendFrameAsync(string, ReadOnlyMemory<byte>, uint, CancellationToken)

Packetises and sends one already-encoded video frame on this track's simulcast rid layer (RFC 8853). The layer must be one of the track's configured SimulcastSendRids; the app encodes each layer at its own resolution/bitrate and calls this once per layer per frame.
