including the failures that motivated a change and the limits a release deliberately kept.

For the machine-readable list of every change, see [`CHANGELOG.md`](../../CHANGELOG.md); it follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and is the file to read when you need to know
*whether* something changed. Read the notes here when you need to know *what it means for you*.
