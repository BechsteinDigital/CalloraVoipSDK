Deeper control for AddAudioTrack(AudioTrackOptions): the track's direction, its codec preferences, and the MediaStream it belongs to. Every field is optional — new AudioTrackOptions() yields a send-recv track using the client's configured AudioCodecs, matching the parameterless AddAudioTrack() happy path. Audio has no simulcast, so there is no per-layer/rid surface here.

Audio codecs to offer on this track, by name (opus, PCMU, PCMA, G722). null (the default) uses the client's configured AudioCodecs. Unknown names are rejected when the track is added.

StreamId

The WebRTC MediaStream id this track belongs to (a=msid stream id, RFC 8830). null (the default) puts the track in the peer's default stream. Tracks that share a stream id are grouped as one remote MediaStream on the receiver.
