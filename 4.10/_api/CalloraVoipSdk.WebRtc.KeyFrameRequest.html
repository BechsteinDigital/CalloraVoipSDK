Remarks

The attribution is what a forwarding layer needs. Given only "someone wants a key frame", a server relaying several participants has no safe move but to ask every sender for one — so in a room of three or more, one receiver's decoder reset produces a key frame from all of them, at the moment the link is already struggling, because that is what made the receiver ask. With the stream named, it asks that source alone.

Parameters

Mid string

The media identification (a=mid) of the track the request is about.

MediaSsrc uint

The media SSRC the PLI or FIR named. Zero when the peer sent no usable SSRC — unattributed, which is deliberately distinct from attributed to the wrong stream.

Rid string

The simulcast layer (a=rid, RFC 8853) that SSRC carries, or null when the track is not simulcasting or the SSRC could not be resolved to a layer.
