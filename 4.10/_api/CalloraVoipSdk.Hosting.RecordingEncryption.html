Factory for the SDK's built-in AES-256-GCM recording encryption. It hands back an IRecordingEncryptionProvider ready to assign to EncryptionProvider, so a consumer can encrypt finalized recording files with the shipped reference implementation without writing their own crypto.

Remarks

The concrete provider (an AES-GCM-HKDF STREAM construction, constant memory regardless of file size) is an internal Infrastructure implementation detail; this Client-layer facade is the public seam that builds it — the same pattern the SDK uses to expose the built-in TURN/STUN servers (ITurnServerHost, IStunServerHost). Keep the returned provider for the whole recording session and dispose it (via RecordingOptions ownership or directly) so its key is zeroed from memory.

using var provider = RecordingEncryption.FromPassphrase("correct horse battery staple", salt);
var options = new RecordingOptions { EncryptionProvider = provider };

The passphrase to derive the key from; must not be null or whitespace.

The PBKDF2 salt; must be at least 8 bytes. Store it alongside the recording so the same key can be re-derived for decryption.

PBKDF2 iteration count; must be at least 10,000. Defaults to 100,000.
