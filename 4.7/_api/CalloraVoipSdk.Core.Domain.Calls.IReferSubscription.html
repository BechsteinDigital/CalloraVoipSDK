Live handle to the implicit subscription created by an accepted inbound SIP REFER (RFC 3515 / RFC 6665). The application places the referred call itself; through this handle it reports that call's progress and final outcome, and the SDK translates each report into a message/sipfrag NOTIFY on the subscription so the transferor sees the real status instead of an optimistic guess.

public interface IReferSubscription

Remarks

Reporting is optional: an accepted REFER already emits an immediate active/100 Trying NOTIFY. If the application never reports, no further NOTIFY is sent and the transferor's subscription lapses at its advertised expiry.

The handle is single-shot on termination: the first of ReportSuccess(int, string?) or ReportFailure(int, string?) closes the subscription; all later reports (progress or terminal) are ignored. All members are thread-safe and non-blocking — a report schedules the NOTIFY and returns without awaiting the network.

Methods

ReportFailure(int, string?)

Reports that the referred call failed — a terminated NOTIFY with the sipfrag SIP/2.0 {statusCode} {reasonPhrase} — and closes the subscription. The first terminal report wins; later reports are ignored.

void ReportFailure(int statusCode, string? reasonPhrase = null)

Parameters

statusCode int

The final 3xx-6xx status code (e.g. 486 Busy Here).

reasonPhrase string

Optional reason phrase; a sensible default is used when null.

ReportPending()

Marks the subscription as pending (RFC 6665 §4.1.3): the transfer was accepted but the referred call has not started yet. Makes the immediate NOTIFY carry Subscription-State: pending instead of active. Only effective when called synchronously inside the transfer handler, before the first NOTIFY is sent; the first subsequent progress report transitions the subscription to active. Ignored once the subscription is already active or terminated.

void ReportPending()

ReportProgress(int, string?)

Reports arbitrary interim progress of the referred call as an active NOTIFY carrying the sipfrag SIP/2.0 {statusCode} {reasonPhrase}. Intended for provisional (1xx) statuses such as 183 Session Progress. Ignored once the subscription has terminated.

void ReportProgress(int statusCode, string? reasonPhrase = null)

Parameters

statusCode int

The provisional SIP status code to report.

reasonPhrase string

Optional reason phrase; a sensible default is used when null.

ReportRinging()

Reports that the referred call is ringing — an active NOTIFY with the sipfrag SIP/2.0 180 Ringing. Ignored once the subscription has terminated.

void ReportRinging()

ReportSuccess(int, string?)

Reports that the referred call completed successfully — a terminated NOTIFY with the sipfrag SIP/2.0 {statusCode} {reasonPhrase} (default 200 OK) — and closes the subscription. The first terminal report wins; later reports are ignored.

void ReportSuccess(int statusCode = 200, string? reasonPhrase = null)

statusCode int
